# GO STORAGE #

An object storage written in GoLang.

You can use as you want, but it is for **STUDY PURPOSES**, I do not recommend use this in a production environment.

## Features ##

+ IAM
+ Public and Private Objects and Buckets
+ Presigned URLs
+ Bucket Isolation
+ Data streaming
+ Auto Content-type
+ Checksum Validation
+ Metadata
+ Rate Limiter
+ Smart Deduplication
